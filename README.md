# Weather Dashboard

Search for any city to see the current conditions and a five-day forecast.

**Live demo:** https://trevor99-afk.github.io/weather-dashboard/

## Features

- City search using the Open-Meteo geocoding API
- Current temperature, feels-like, humidity and wind
- Five-day forecast
- Celsius and Fahrenheit toggle
- Remembers your last city and unit choice
- Loading, not-found and network error states

## Built with

HTML, CSS and plain JavaScript, using `fetch` with the free [Open-Meteo](https://open-meteo.com/) API. No API key is needed.

## Run it locally

Open `index.html` in a browser.
